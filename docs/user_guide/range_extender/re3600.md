## III. Manage

### 1. System Status

On the System Status page, you can check the status of the range extender system, including:

- [Devices](system_status.md#device){ data-preview }: shows the number of devices connected to this range extender, via Ethernet cable or 2.4G WiFi or 5G WiFi. Click *More Details* to know more information about these devices.
- [Host Network](system_status.md#host-network){ data-preview }: shows the status, SSID and signal about the Host Network being extended by this Range Extender. Click *More Details* to know more information about it or make changes on Settings page. 
- [Wireless 2.4G](system_status.md#wireless-24g){ data-preview }: shows the extended Wireless 2.4G status, SSID and channel. Click *More Details* to know more information about it or make changes on Settings page. 
- [Wireless 5G](system_status.md#wireless-5g){ data-preview }: shows the extended Wireless 5G status, SSID and channel. Click *More Details* to know more information about it or make changes on Settings page. 
- [LAN](system_status.md#lan){ data-preview }: shows the LAN port status, IP address and subnet mask. Click *More Details* to know more information about it or make changes.
- [System](system_status.md#system){ data-preview }: shows the system firmware version, local time and uptime. Click *More Details* to view more information about it or make changes on Settings page.

### 4. Diagnostic Tools

#### 4.1 - [PING](diagnostic_tools.md#ping){ data-preview } 
Used to test the connectivity between the range extender and the tested host, and measure the round-trip time. 

#### 4.2 - [TRACEROUTE](diagnostic_tools.md#traceroute){ data-preview }
Used to test the route (path) your range extender has passed to reach the tested host, and measure transit delays of packets across an Internet Protocol network. 

#### 4.3 - [NSLOOKUP](diagnostic_tools.md#nslookup){ data-preview }
Check if the DNS IP address of the WAN can work normally.

#### 4.4 - [System Log](diagnostic_tools.md#system-log){ data-preview }
Track all the range extender behaviors. When the range extender does not work normally, download the system log and send it to our Technical Support for troubleshooting.
