### 2. [General Settings](general_settings.md){ data-preview }

!!! Note
     In AP Controller mode, *WAN Mode* and *VPN* are NOT available for configuration.

- [AP Management](general_settings.md#ap-management){ data-preview }: Centralized control, configuration, and monitoring of wireless APs (Access Points), including auto-discovery, group policies, and real-time status tracking.    
- [Clients](general_settings.md#clients){ data-preview }: Configure and manage wireless network settings for the controlled APs.
- [Wireless](general_settings.md#wireless){ data-preview }: Configure and manage wireless network settings for the controlled APs.
- [Captive Portal](general_settings.md#captive-portal){ data-preview }: Allow you to design a portal page for network access verification. 
- [WAN Mode](general_settings.md#wan-mode){ data-preview }: Set your Internet connection. Select your Internet connection type and configure the required parameters.
- [LAN](general_settings.md#lan){ data-preview }: Modify the AP controller's LAN IP address, when necessary.
- [DHCP Server](advanced_settings_network.md#dhcp-server){ data-preview }: Specify the IP address for client devices by the AP controller as a DHCP Server.
- [PoE](general_settings.md#poe){ data-preview }: Allow remote control of power delivery to connected access points via Ethernet cables.
- [VPN](general_settings.md#vpn){ data-preview }: Help to access Internet resources remotely, securely, and privately through tunneling technology.
- [Firmware](general_settings.md#firmware){ data-preview }: Update the AP controller's firmware to be the latest version.

### 3. Advanced Settings

#### 3.1 [Network](advanced_settings_network.md){ data-preview }

!!! Note
     In AP Controller mode, only *LAN*, *DHCP Server*, *Wake on LAN* and *USB Sharing* are available for configuration.

- [IPv6](advanced_settings_network.md#ipv6){ data-preview }: Set up an IPv6 Connection. 
- [IGMP](advanced_settings_network.md#igmp){ data-preview }:  Manage and optimize multicast traffic for the client devices, like IPTV.
- [QoS](advanced_settings_network.md#qos){ data-preview }: Prioritize connection of specific devices for a certain duration. 
- [Custom DNS](advanced_settings_network.md#custom-dns){ data-preview }: Customize a DNS server to be resolved through for DNS names. 
- [DDNS](advanced_settings_network.md#ddns){ data-preview }: Map a domain name to the dynamic IP address of a network device. 
- [Static Routing](advanced_settings_network.md#static-routing){ data-preview }: Manually configure routings for data forwarding. 
- [Port Forwards](advanced_settings_network.md#port-forwards){ data-preview }: Set up public services on your local network with higher security. 
- [Port Trigger](advanced_settings_network.md#port-trigger){ data-preview }: Specify a triggering port and its corresponding external ports. 
- [DMZ](advanced_settings_network.md#dmz){ data-preview }: Disable DMZ unless necessary.
- [Online Detection](advanced_settings_network.md#online-detection){ data-preview }: Ensure your network always online and operational. 
- [TTL](advanced_settings_network.md#ttl){ data-preview }: Set the maximum time for packets to survive in the network. 
- [Wake on LAN](advanced_settings_network.md#wake-on-lan){ data-preview }: Allow a computer to be turned on or awakened by a network message.
- [UPnP](advanced_settings_network.md#upnp){ data-preview }: Allow applications or host devices to automatically find the front-end NAT device. 
- [USB Sharing](advanced_settings_network.md#usb-sharing){ data-preview }: Allow network-connected devices to access the shared files in the USB devices connected to the AP controller.

#### 3.2 [Security](advanced_settings_security.md){ data-preview }

!!! Note
     In AP Controller mode, ONLY *Wi-Fi Schedule* is available for configuration.

- [Firewall](advanced_settings_security.md#firewall){ data-preview }: Monitor and control incoming and outgoing network traffic based on predetermined security rules.
- [MAC Filter](advanced_settings_security.md#mac-filter){ data-preview }: Prevent unauthorized devices with certain MAC address from accessing the network.
- [IP Filter](advanced_settings_security.md#ip-filter){ data-preview }: Block or allow traffic to your network or system based on the IP addresses. 
- [Domain Filter](advanced_settings_security.md#domain-filter){ data-preview }: Control or limit access to specific websites or Internet services by filtering domain name requests. 
- [IP/MAC Binding](advanced_settings_security.md#ipmac-binding){ data-preview }: Bind network device's IP address to its MAC address. 
- [ALG](advanced_settings_security.md#alg){ data-preview }: Inspect and modify application-layer data in network traffic to allow it to pass through firewalls and other security devices more easily.
- [WiFi Schedule](advanced_settings_security.md#wifi-schedule){ data-preview }: Turn on/off the AP controller's wireless network automatically at a specific time.

#### 3.3 [System](advanced_settings_system.md){ data-preview }

!!! Note
     In AP Controller mode, TR069 is NOT available.

- [System Time](advanced_settings_system.md#system-time){ data-preview }: Configure the AP controller's system time, necessary for some time-based functions.
- [Auto Upgrade](advanced_settings_system.md#auto-upgrade){ data-preview }: Schedule to automatically upgrade the firmware to the latest version.
- [Backup/Restore](advanced_settings_system.md#backuprestore){ data-preview }: Backup the configuration file or restore it.
- [Administration](advanced_settings_system.md#administration){ data-preview }: Access and manage the AP controller from the local or remote devices.
- [Admin Account](advanced_settings_system.md#admin-account){ data-preview }: Change the AP controller's login password.
- [Language](advanced_settings_system.md#language){ data-preview }: Customize the AP controller's web management language.
- [Timed Reboot](advanced_settings_system.md#timed-reboot){ data-preview }: Schedule for the AP controller rebooting.
- [Reboot](advanced_settings_system.md#reboot){ data-preview }: Reboot the AP controller for the settings or changes to take effect.
- [Reset](advanced_settings_system.md#reset){ data-preview }: Restore the AP controller to its factory default settings.
- [TR069](advanced_settings_system.md#tr069){ data-preview }: Configure the AP controller's TR069 (CPE WAN Management).
- [Operation Mode](advanced_settings_system.md#operation-mode){ data-preview }: Switch Operation Mode between *Main Router and AP Controller* and *AP Controller*.
- [Cloud Management](advanced_settings_system.md#cloud-management){ data-preview }: Enable Cloud Management.
- [SSH](advanced_settings_system.md#ssh){ data-preview }: Enables SSH access for debugging purposes. Only enable this when requested by technical support.

### 4. Diagnostic Tools
- [Diagnosis](diagnostic_tools.md#diagnosis){ data-preview }: Automatically check AP health and generates troubleshooting reports.
- [PING](diagnostic_tools.md#ping){ data-preview }: Used to test the connectivity between the AP controller and the tested host, and measure the round-trip time.
- [TRACEROUTE](diagnostic_tools.md#traceroute){ data-preview }: Used to test the route or path your AP controller has passed to reach the tested host, and measure transit delays of packets across an Internet Protocol network.
- [NSLOOKUP](diagnostic_tools.md#nslookup){ data-preview }: Query DNS servers to resolve domain names into IP addresses.
- [System Log](diagnostic_tools.md#system-log){ data-preview }: Track all the AP controller behaviors.
