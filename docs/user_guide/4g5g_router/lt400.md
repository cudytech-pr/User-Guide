## Manage

### 1. [System Status](system_status.md){ data-preview }

On the [System Status](system_status.md){ data-preview } page, you can check the status of the router system, including Status, Devices, Cellular, WAN, LAN, WISP, Wireless 2.4G, VPN, DHCP Server, and System.

### 2. General Settings
- 2.1 [Cellular](general_settings_cellular.md#APN){ data-preview }: Configure the cellular network features, including APN, Data Settings and Modem Reset.
- 2.2 [WAN Mode](general_settings_wan.md){ data-preview }: is to set your Internet connection. Select your Internet connection type from the drop-down list of Protocol. Follow the instructions on the page to complete the configuration.
- 2.3 [WISP](general_settings_wisp.md){ data-preview }: Enable the router to wirelessly connect to a distant Wi-Fi network and share that connection locally via Ethernet/Wi-Fi, acting as a client bridge.
- 2.4 [Wireless 2.4G](general_settings_wireless_2.4g.md){ data-preview }: is to customize the router's wireless settings, including SSID and password, mode, channel, channel width and transmit power, and so on.
- 2.5 [VPN](general_settings_vpn.md){ data-preview }: namely, Virtual Private Network, helps you access Internet resources remotely, securely, and privately through tunneling technology. When you access the Internet, VPN encrypts your personal information and hides your IP address from the public. For VPN users, it looks like the devices are directly connected. 

### 3. Advanced Settings

#### 3.1 [Network](advanced_settings_network.md){ data-preview }
- [LAN/WAN Switch](advanced_settings_network.md#lanwan-switch){ data-preview }: Switch the WAN/LAN port between local network switching (LAN mode) and wide-area routing (WAN mode).
- [LAN](advanced_settings_network.md#lan){ data-preview }: Modify the router's LAN IP address, when necessary.
- [Guest Network](advanced_settings_network.md#guest-network){ data-preview }: Create a guest network without disturbing the main network's security and privacy.
- [DHCP Server](advanced_settings_network.md#dhcp-server){ data-preview }: Specify the IP address for client devices by the router as a DHCP Server.
- [IPv6](advanced_settings_network.md#ipv6){ data-preview }: Set up an IPv6 Connection.
- [QoS](advanced_settings_network.md#qos){ data-preview }: Prioritize connection of specific devices for a certain duration. 
- [Custom DNS](advanced_settings_network.md#custom-dns){ data-preview }: Customize a DNS server to be resolved through for DNS names.
- [DDNS](advanced_settings_network.md#ddns){ data-preview }: Map a domain name to the dynamic IP address of a network device.
- [Static Routing](advanced_settings_network.md#static-routing){ data-preview }: Manually configure routings for data forwarding.
- [Port Forwards](advanced_settings_network.md#port-forwards){ data-preview }: Set up public services on your local network with higher security.
- [Port Trigger](advanced_settings_network.md#port-trigger){ data-preview }: Specify a triggering port and its corresponding external ports.
- [DMZ](advanced_settings_network.md#dmz){ data-preview }: Disable DMZ unless necessary.
- [TTL](advanced_settings_network.md#ttl){ data-preview }: Set the maximum time for packets to survive in the network.
- [UPnP](advanced_settings_network.md#upnp){ data-preview }: Allow applications or host devices to automatically find the front-end NAT device.

#### 3.2 [Security](advanced_settings_security.md){ data-preview }
- [Firewall](advanced_settings_security.md#firewall){ data-preview }: Monitor and control incoming and outgoing network traffic based on predetermined security rules.
- [MAC Filter](advanced_settings_security.md#mac-filter){ data-preview }: Prevent unauthorized devices with certain MAC address from accessing the network.
- [IP Filter](advanced_settings_security.md#ip-filter){ data-preview }: Block or allow traffic to your network or system based on the IP addresses. 
- [Domain Filter](advanced_settings_security.md#domain-filter){ data-preview }: Control or limit access to specific websites or Internet services by filtering domain name requests. 
- [IP/MAC Binding](advanced_settings_security.md#ipmac-binding){ data-preview }: Bind network device's IP address to its MAC address. 
- [WPS](advanced_settings_security.md#wps){ data-preview }: Set up a security-protected Wi-Fi connection without sharing/entering credentials. 
- [WiFi Schedule](advanced_settings_security.md#wifi-schedule){ data-preview }: Turn on/off the router's wireless network automatically at a specific time.
- [Remote Web](advanced_settings_security.md#remote-web){ data-preview }: Allow remote access to the router via the configured listen port and IP address.
- [ALG](advanced_settings_security.md#alg){ data-preview }: Inspect and modify application-layer data in network traffic to allow it to pass through firewalls and other security devices more easily.

#### 3.3 [System](advanced_settings_system.md){ data-preview }
- [Timezone](advanced_settings_system.md#system-time){ data-preview }: Select your timezone to specify the router's system time, necessary for some time-based functions.
- [Firmware](advanced_settings_system.md#firmware){ data-preview }: Upgrade the firmware to the latest version.
- [Backup/Restore](advanced_settings_system.md#backuprestore){ data-preview }: Backup the configuration file or restore it.
- [Administration](advanced_settings_system.md#administration){ data-preview }: Access and manage the router from the local or remote devices.
- [Admin Account](advanced_settings_system.md#admin-account){ data-preview }: Change the router's login password.
- [Language](advanced_settings_system.md#language){ data-preview }: Customize the router's web management language.
- [Timed Reboot](advanced_settings_system.md#timed-reboot){ data-preview }: Schedule for the router rebooting.
- [Reboot](advanced_settings_system.md#reboot){ data-preview }: Reboot the router for the settings or changes to take effect.
- [Reset](advanced_settings_system.md#reset){ data-preview }: Restore the router to its factory default settings.

### 4. Diagnostic Tools
- 4.1 [Diagnosis](diagnostic_tools.md#diagnosis){ data-preview }: The diagnosis result will indicate the status of Internet, Wireless, Devices, Services and System. You can click Download to reserve the diagnosis bin file. 
- 4.2 [PING](diagnostic_tools.md#ping){ data-preview }: Used to test the connectivity between the router and the tested host, and measure the round-trip time. 
- 4.3 [TRACEROUTE](diagnostic_tools.md#traceroute){ data-preview }: Used to test the route (path) your router has passed to reach the tested host, and measure transit delays of packets across an Internet Protocol network. 
- 4.4 [NSLOOKUP](diagnostic_tools.md#nslookup){ data-preview }: Check if the DNS IP address of the WAN can work normally. 
- 4.5 [System Log](diagnostic_tools.md#system-log){ data-preview }: Track all the router behaviors. When the router does not work normally, download the system log and send it to our Technical Support for troubleshooting.
