## Manage

### 1. [System Status](system_status.md){ data-preview }

- In Mesh Wi-Fi Router mode, it includes Status, Mesh, Devices, WAN, LAN, Wireless 2.4G, Wireless 5G, VPN, DHCP Server, and System;
- In Mesh Access Point mode, it includes Status, Devices, LAN, Wireless 2.4G, Wireless 5G, DHCP Server, and System.

### 2. [General Settings](general_settings.md){ data-preview }

- [WAN Mode](general_settings.md#wan-mode){ data-preview }: is to set your Internet connection. Select your Internet connection type from the drop-down list of Protocol. Follow the instructions on the page to complete the configuration.
- [Wireless](general_settings.md#wireless){ data-preview }: is to customize the Mesh router's wireless settings, including SSID and password, mode, channel, channel width and transmit power, and so on.
- [VPN](general_settings.md#vpn){ data-preview }: namely, Virtual Private Network, helps you access Internet resources remotely, securely, and privately through tunneling technology. When you access the Internet, VPN encrypts your personal information and hides your IP address from the public. For VPN users, it looks like the devices are directly connected. 
- [Captive Portal](captive_portal.md){ data-preview }: allows you to design a portal page for network access verification. Customers are directed to view an advertisement or accept set terms before being granted Internet access. In this way, it offers unique marketing opportunities for small businesses to improve brand awareness and deliver marketing messages. 
- [Firmware](general_settings.md#firmware){ data-preview }: Update the Mesh router's firmware to be the latest version.

### 3. Parental Control

- [Parental Control](parental_control.md){ data-preview } helps to set up unique restrictions on Internet access for each member of your family via Parental Control feature. You can block inappropriate content, set daily limits for the total time spent online and restrict Internet access to certain time of the day, etc. **This feature only works in Wireless router mode.**

### 4. Advanced Settings

#### [- Network](advanced_settings_network.md){ data-preview }

- [LAN](advanced_settings_network.md#lan){ data-preview }: Modify the Mesh router's LAN IP address, when necessary.
- [Guest Network](general_settings.md#guest-network){ data-preview }: Create a guest network without disturbing the main network's security and privacy.
- [DHCP Server](advanced_settings_network.md#dhcp-server){ data-preview }: Specify the IP address for client devices by the Mesh router as a DHCP Server.
- [IPv6](advanced_settings_network.md#ipv6){ data-preview }: Set up an IPv6 Connection.
- [IGMP](advanced_settings_network.md#igmp){ data-preview }:  Manage and optimize multicast traffic for the client devices, like IPTV.
- [IPTV/VLAN](general_settings.md#iptvvlan){ data-preview }:  Enjoy IPTV or VoIP service.
- [QoS](advanced_settings_network.md#qos){ data-preview }: Prioritize connection of specific devices for a certain duration. 
- [Custom DNS](advanced_settings_network.md#custom-dns){ data-preview }: Customize a DNS server to be resolved through for DNS names.
- [DDNS](advanced_settings_network.md#ddns){ data-preview }: Map a domain name to the dynamic IP address of a network device.
- [Static Routing](advanced_settings_network.md#static-routing){ data-preview }: Manually configure routings for data forwarding.
- [Port Forwards](advanced_settings_network.md#port-forwards){ data-preview }: Set up public services on your local network with higher security.
- [Port Trigger](advanced_settings_network.md#port-trigger){ data-preview }: Specify a triggering port and its corresponding external ports.
- [DMZ](advanced_settings_network.md#dmz){ data-preview }: Disable DMZ unless necessary.
- [Online Detection](advanced_settings_network.md#online-detection){ data-preview }: Ensure your network always online and operational.
- [TTL](advanced_settings_network.md#ttl){ data-preview }: Set the maximum time for packets to survive in the network.
- [Wake on LAN](advanced_settings_network.md#wake-on-lan){ data-preview }: Allow a computer to be turned on or awakened by a network message.
- [UPnP](advanced_settings_network.md#upnp){ data-preview }: Allow applications or host devices to automatically find the front-end NAT device.

#### [- Security](advanced_settings_security.md){ data-preview }

- [Firewall](advanced_settings_security.md#firewall){ data-preview }: Monitor and control incoming and outgoing network traffic based on predetermined security rules.
- [MAC Filter](advanced_settings_security.md#mac-filter){ data-preview }: Prevent unauthorized devices with certain MAC address from accessing the network.
- [IP Filter](advanced_settings_security.md#ip-filter){ data-preview }: Block or allow traffic to your network or system based on the IP addresses. 
- [Domain Filter](advanced_settings_security.md#domain-filter){ data-preview }: Control or limit access to specific websites or Internet services by filtering domain name requests. 
- [IP/MAC Binding](advanced_settings_security.md#ipmac-binding){ data-preview }: Bind network device's IP address to its MAC address. 
- [WPS](advanced_settings_security.md#wps){ data-preview }: Set up a security-protected Wi-Fi connection without sharing/entering credentials. 
- [WiFi Schedule](advanced_settings_security.md#wifi-schedule){ data-preview }: Turn on/off the Mesh router's wireless network automatically at a specific time.
- [ALG](advanced_settings_security.md#alg){ data-preview }: Inspect and modify application-layer data in network traffic to allow it to pass through firewalls and other security devices more easily.

#### [- System](advanced_settings_system.md){ data-preview }

- [System Time](advanced_settings_system.md#system-time){ data-preview }: Configure the Mesh router's system time, necessary for some time-based functions.
- [Firmware](advanced_settings_system.md#firmware){ data-preview }: Upgrade the firmware to the latest version.
- [Backup/Restore](advanced_settings_system.md#backuprestore){ data-preview }: Backup the configuration file or restore it.
- [Administration](advanced_settings_system.md#administration){ data-preview }: Access and manage the Mesh router from the local or remote devices.
- [Admin Account](advanced_settings_system.md#admin-account){ data-preview }: Change the Mesh router's login password.
- [Language](advanced_settings_system.md#language){ data-preview }: Customize the Mesh router's web management language.
- [Timed Reboot](advanced_settings_system.md#timed-reboot){ data-preview }: Schedule for the Mesh router rebooting.
- [Reboot](advanced_settings_system.md#reboot){ data-preview }: Reboot the Mesh router for the settings or changes to take effect.
- [Reset](advanced_settings_system.md#reset){ data-preview }: Restore the Mesh router to its factory default settings.
- [LED Control](advanced_settings_system.md#led-control){ data-preview }: Control the Mesh router's LED.
- [TR069](advanced_settings_system.md#tr069){ data-preview }: Configure the Mesh router's TR069 (CPE WAN Management).

### 5. Diagnostic Tools

- [Diagnosis](diagnostic_tools.md#diagnosis){ data-preview }: The diagnosis result will indicate the status of Internet, Wireless, Devices, Services and System. You can click Download to reserve the diagnosis bin file. 
- [PING](diagnostic_tools.md#ping){ data-preview }: Used to test the connectivity between the Mesh router and the tested host, and measure the round-trip time. 
- [TRACEROUTE](diagnostic_tools.md#traceroute){ data-preview }: Used to test the route (path) your Mesh router has passed to reach the tested host, and measure transit delays of packets across an Internet Protocol network. 
- [NSLOOKUP](diagnostic_tools.md#nslookup){ data-preview }: Check if the DNS IP address of the WAN can work normally. 
- [System Log](diagnostic_tools.md#system-log){ data-preview }: Track all the Mesh router behaviors. When the Mesh router does not work normally, download the system log and send it to our Technical Support for troubleshooting.
