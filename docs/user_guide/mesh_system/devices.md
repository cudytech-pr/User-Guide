# Devices

- *Status* shows the number of devices connected to this Router, including 2.4G/5G/6G WiFi, Wired and Mesh devices.
    <img src="https://cdn.jsdelivr.net/gh/Cudytech-pr/User-Guide/docs/images/mesh_system/devices.webp" alt="" width="800px" style="border: 1px solid #eee;" />

- *Devices* allows for some settings about these connected devices.
    <img src="https://cdn.jsdelivr.net/gh/Cudytech-pr/User-Guide/docs/images/mesh_system/devices2.webp" alt="" width="800px" style="border: 1px solid #eee;" />

    - Internet: Click to enable/disable the Internet for the devices.
    - VPN: Click to enable/disable VPN for the devices.
    - Operation: Click to pop up the editing page as below, where you can customize the device name and limit the download/upload rate.
