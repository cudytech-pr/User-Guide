# System Status

On the *System Status* page, you can check the status of the Mesh router system, including Status, Devices, WAN, LAN, Wireless 2.4G, Wireless 5G, IPv6, VPN, DHCP Server, and System.

<img src="https://cdn.jsdelivr.net/gh/Cudytech-pr/User-Guide/docs/images/mesh_system/system-status.webp" alt="" width="800px" style="border: 1px solid #eee;" />

!!! Note
    M1200 is used as an example in this guide. Refer to your actual product for more details.

- **Status** shows whether the Mesh router has connected to the Internet or not, and its work mode and interface. Click [*Quick Setup*](qig.md){ data-preview } to redirect to the *Quick Setup* page.

- [Mesh](mesh.md){ data-preview } (not available for all models. refer to your specific model) shows the main Mesh router's Mesh network status (SOLE or MESH), the mesh device name and the amount of mesh units. Click *More Details* to know more information or add/manage mesh unit(s).

- **Devices** shows the number of devices connected to this Mesh router, via Ethernet cable or 2.4G WiFi or 5G WiFi. Click *More Details* to know more information about these devices or configure the settings.

    - Internet: Click to enable/disable the Internet for the devices.
    - VPN: Click to enable/disable VPN for the devices.
    - Operation: Click to pop up the editing page as below, where you can customize the device name and limit the download/upload rate.

- [WAN](general_settings.md#wan-mode){ data-preview } shows the WAN port connection status. Click *More Details* to know more information about it or make changes on Settings page. 

- [LAN](advanced_settings_network.md#lan){ data-preview } shows the connected LAN port status. Click *More Details* to know more information about it or make changes.

- [WISP](general_settings.md#wisp){ data-preview } (not available for all models. refer to your specific model) shows the connected HOST Network status, its SSID and Upload/Download speed. Click *More Details* to know more information about it or make changes.

- [Wireless 2.4G](general_settings.md#wireless#24g5g){ data-preview } shows the Wireless 2.4G status. Click *More Details* to know more information about it or make changes on Settings page. 

- [Wireless 5G](general_settings.md#wireless#24g5g){ data-preview } (not available for all models. refer to your specific model) shows the Wireless 5G status. Click *More Details* to know more information about it or make changes on Settings page. 

- [Wireless 6G](general_settings.md#wireless#6g){ data-preview } (not available for all models. refer to your specific model) shows the Wireless 6G status. Click *More Details* to know more information about it or make changes on Settings page. 

- [VPN](general_settings.md#vpn){ data-preview } shows VPN connection status. Click *More Details* to know more information about it or make changes on Settings page.

- [DHCP Server](advanced_settings_network.md#dhcp-server){ data-preview } shows the DHCP Server status. Click *More Details* to know more information about it or make changes on Settings page.

- **System** shows the System status. Click *More Details* to view more information about it or make changes on Settings page.

    - *Status* shows the Router info about firmware version, model, hardware version, local time and uptime.
        <img src="https://cdn.jsdelivr.net/gh/Cudytech-pr/User-Guide/docs/images/4g5g_router/system_status_1.webp" alt="" width="800px" style="border: 1px solid #eee;" />

    - *Statistics* shows the detailed traffic information of each interface in the statistics list.
        <img src="https://cdn.jsdelivr.net/gh/Cudytech-pr/User-Guide/docs/images/4g5g_router/system_status_2.webp" alt="" width="800px" style="border: 1px solid #eee;" />

    - *ARP* lists the connected devices' IP address with its bound MAC address, Hostname and Interfaces.
        <img src="https://cdn.jsdelivr.net/gh/Cudytech-pr/User-Guide/docs/images/4g5g_router/system_status_3.webp" alt="" width="800px" style="border: 1px solid #eee;" />

    - *Active IP Routes* table contains a list of routes to network destinations associated with and known by the Router.
        <img src="https://cdn.jsdelivr.net/gh/Cudytech-pr/User-Guide/docs/images/4g5g_router/system_status_4.webp" alt="" width="800px" style="border: 1px solid #eee;" />

    - *System Log* tracks all the Router behaviors. It is used for [*technical support*](mailto:support@cudy.com) to diagnose and troubleshoot for the Router.  It is also available on *Diagnostic Tools -> System Log* page.
        <img src="https://cdn.jsdelivr.net/gh/Cudytech-pr/User-Guide/docs/images/4g5g_router/system_status_5.webp" alt="" width="800px" style="border: 1px solid #eee;" />

        - Update: Click to refresh the system log.
        - Clear: Click to erase all the system log up till now.
        - Download: Click to download the system log for technical support.
