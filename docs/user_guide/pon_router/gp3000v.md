# GP3000V

## Overview
- Check the [package content](overview_gp3000v.md#package-content){ data-preview }.
- View the router's [appearance](overview_gp3000v.md#front-panel){ data-preview }.

## Connect
- Finish the [Hardware Connection](connection.md){ data-preview } for the router.

## Manage

Open a web browser on the device connected. Enter *cudy.net* (or *192.168.1.1*) in the address bar and press *Enter*. Create an administrator password to log in to manage the router.

### 1. [System Status](system_status.md){ data-preview }

On the [System Status](system_status.md){ data-preview } page, you can check the system status of the PON router, including PON Status, PON WAN, VoIP, LAN, Mesh, Devices, Wireless 2.4G, Wireless 5G, DHCP Server, and System.

### 2. [General Settings](general_settings.md){ data-preview }

- [PON WAN](general_settings.md#pon-wan){ data-preview }: Configure the PON WAN connection, including VLAN settings, connection mode, and service type.
- [PON Auth](general_settings.md#pon-auth){ data-preview }: Configure the authentication credentials required to connect to your ISP's PON network.
- [Wireless](general_settings.md#wireless){ data-preview }: Customize the router's wireless settings, including SSID and password, mode, channel, channel width and transmit power, and so on.
- [Guest Network](general_settings.md#guest-network){ data-preview }: Create a guest network without disturbing the main network's security and privacy.
- [EasyMesh](general_settings.md#easymesh){ data-preview }: Connect multiple compatible routers or extenders to create a unified Wi-Fi network with extended coverage and seamless roaming.
- [Firmware](general_settings.md#firmware){ data-preview }: Update the router's firmware to be the latest version.

### 3. [Parental Control](parental_control.md){ data-preview } 

*[Parental Control](parental_control.md){ data-preview }* helps to set up unique restrictions on Internet access for each member of your family via Parental Control feature. You can block inappropriate content, set daily limits for the total time spent online and restrict Internet access to certain time of the day, etc.

### 4. Advanced Settings

#### 4.1 [Network](advanced_settings_network.md){ data-preview }

- [LAN](advanced_settings_network.md#lan){ data-preview }: Modify the router's LAN IP address, when necessary.
- [DHCP Server](advanced_settings_network.md#dhcp){ data-preview }: Specify the IP address for client devices by the router as a DHCP Server.
- [IPv6](advanced_settings_network.md#ipv6){ data-preview }: Set up an IPv6 Connection.
- [IGMP](advanced_settings_network.md#igmp){ data-preview }:  Manage and optimize multicast traffic for the client devices, like IPTV.
- [Custom DNS](advanced_settings_network.md#custom-dns){ data-preview }: Customize a DNS server to be resolved through for DNS names.
- [DDNS](advanced_settings_network.md#ddns){ data-preview }: Map a domain name to the dynamic IP address of a network device.
- [Static Routing](advanced_settings_network.md#static-routing){ data-preview }: Manually configure routings for data forwarding.
- [Port Forwards](advanced_settings_network.md#port-forwards){ data-preview }: Set up public services on your local network with higher security.
- [Port Trigger](advanced_settings_network.md#port-trigger){ data-preview }: Specify a triggering port and its corresponding external ports.
- [DMZ](advanced_settings_network.md#dmz){ data-preview }: Disable DMZ unless necessary.
- [Online Detection](advanced_settings_network.md#online-detection){ data-preview }: Ensure your network always online and operational.
- [TTL](advanced_settings_network.md#ttl){ data-preview }: Set the maximum time for packets to survive in the network.
- [Wake on LAN](advanced_settings_network.md#wake-on-lan){ data-preview }: Allow a computer to be turned on or awakened by a network message.
- [UPnP](advanced_settings_network.md#upnp){ data-preview }: Allow applications or host devices to automatically find the front-end NAT device.
- [USB Sharing](advanced_settings_network.md#usb-sharing){ data-preview }: Share files and data via USB storage device. 
- [VoIP Basic Settings](advanced_settings_network.md#voip-basic-settings){ data-preview }: Configure SIP server information, proxy settings, and telephone line accounts to enable VoIP services through your router.
- [VoIP Advanced Settings](advanced_settings_network.md#voip-advanced-settings){ data-preview }: Configure additional options for customizing SIP communication.
- [WAN Mode](advanced_settings_network.md#wan-mode){ data-preview }: Select the network access technology used by the router.
- [Captive Portal](advanced_settings_network.md#captive-portal){ data-preview }: Customize a portal page for network access verification.


#### 4.2 [Security](advanced_settings_security.md){ data-preview }

- [Firewall](advanced_settings_security.md#firewall){ data-preview }: Monitor and control incoming and outgoing network traffic based on predetermined security rules.
- [MAC Filter](advanced_settings_security.md#mac-filter){ data-preview }: Prevent unauthorized devices with certain MAC address from accessing the network.
- [IP Filter](advanced_settings_security.md#ip-filter){ data-preview }: Block or allow traffic to your network or system based on the IP addresses. 
- [Domain Filter](advanced_settings_security.md#domain-filter){ data-preview }: Control or limit access to specific websites or Internet services by filtering domain name requests. 
- [IP/MAC Binding](advanced_settings_security.md#ipmac-binding){ data-preview }: Bind network device's IP address to its MAC address. 
- [WPS](advanced_settings_security.md#wps){ data-preview }: Set up a security-protected Wi-Fi connection without sharing/entering credentials. 
- [WiFi Schedule](advanced_settings_security.md#wifi-schedule){ data-preview }: Turn on/off the router's wireless network automatically at a specific time.
- [ALG](advanced_settings_security.md#alg){ data-preview }: Inspect and modify application-layer data in network traffic to allow it to pass through firewalls and other security devices more easily.

#### 4.3 [System](advanced_settings_system.md){ data-preview }

- [System Time](advanced_settings_system.md#system-time){ data-preview }: Configure the router's system time, necessary for some time-based functions.
- [Backup/Restore](advanced_settings_system.md#backuprestore){ data-preview }: Backup the configuration file or restore it.
- [Administration](advanced_settings_system.md#administration){ data-preview }: Access and manage the router from the local or remote devices.
- [Admin Account](advanced_settings_system.md#admin-account){ data-preview }: Change the router's login password.
- [Language](advanced_settings_system.md#language){ data-preview }: Customize the router's web management language.
- [Timed Reboot](advanced_settings_system.md#timed-reboot){ data-preview }: Schedule for the router rebooting.
- [Reboot](advanced_settings_system.md#reboot){ data-preview }: Reboot the router for the settings or changes to take effect.
- [Reset](advanced_settings_system.md#reset){ data-preview }: Restore the router to its factory default settings.
- [LED Control](advanced_settings_system.md#led-control){ data-preview }: Control the router's LED.
- [TR069](advanced_settings_system.md#tr069){ data-preview }: Configure the router's TR069 (CPE WAN Management).

### 5. [Diagnostic Tools](diagnostic_tools.md#diagnosis){ data-preview }

- [Diagnosis](diagnostic_tools.md#diagnosis){ data-preview }: The diagnosis result will indicate the status of Internet, Wireless, Devices, Services and System. You can click Download to reserve the diagnosis bin file. 
- [PING](diagnostic_tools.md#ping){ data-preview }: Used to test the connectivity between the router and the tested host, and measure the round-trip time. 
- [TRACEROUTE](diagnostic_tools.md#traceroute){ data-preview }: Used to test the route (path) your router has passed to reach the tested host, and measure transit delays of packets across an Internet Protocol network. 
- [NSLOOKUP](diagnostic_tools.md#nslookup){ data-preview }: Check if the DNS IP address of the WAN can work normally. 
- [System Log](diagnostic_tools.md#system-log){ data-preview }: Track all the router behaviors. When the router does not work normally, download the system log and send it to our Technical Support for troubleshooting.
