
# How to Remotely Manage Your Cloud Easy-Managed Switch Using the Cudy App?
 
1. Use an Ethernet cable to connect your cloud easy-managed switch to your computer. Set the computer's IP address to *192.168.2.x* (x ranges from 2 to 254) and subnet mask to *255.255.255.0*.

2. Open a web browser on the computer, enter *192.168.2.1* in the address bar and press *Enter*. 

3. For the initial login, create a new password. If you already configured a password, enter it to log in. If the password is forgotten, press and hold the Reset button to restore factory settings.
    <img src="https://cdn.jsdelivr.net/gh/Cudytech-pr/User-Guide/docs/images/tutorial/login2.webp" width="300px" style="display: block; margin: 0 auto;border: 1px solid #eee;">    

4. *Enable* Cloud Management, Dynamic lP and Auto DNS. (Serial Number may be needed if the QR code cannot be scanned.)

5. When it appears *waits to get DHCP address...*, set your computer to *Obtain an IP address automatically* and *Obtain DNS server address automatically*.
    <img src="https://cdn.jsdelivr.net/gh/Cudytech-pr/User-Guide/docs/images/tutorial/login3.webp" width="300px" style="display: block; margin: 0 auto;border: 1px solid #eee;">    

6. On your smart phone/tablet, download and open the Cudy App. Log in to your Cudy account (register first if you don't have one). 

7. Tap the menu icon (☰) on the left of Dashboard and select *Switch*.
    <img src="https://cdn.jsdelivr.net/gh/Cudytech-pr/User-Guide/docs/images/tutorial/dashboard.webp" width="300px" style="display: block; margin: 0 auto;border: 1px solid #eee;">    

    <img src="https://cdn.jsdelivr.net/gh/Cudytech-pr/User-Guide/docs/images/tutorial/switch.webp" width="300px" style="display: block; margin: 0 auto;border: 1px solid #eee;">    

7. On the Dashboard (Switch), select to *Scan Serial Number* (recommended) or *Input Serial Number*. (Ensure the switch is connected to the Internet before adding it.)
    <img src="https://cdn.jsdelivr.net/gh/Cudytech-pr/User-Guide/docs/images/tutorial/dashboard2.webp" width="300px" style="display: block; margin: 0 auto;border: 1px solid #eee;">    

8. Verify the Serial Number, and enter the management password (same as the web management password). Tap the ✔ icon at the top right.
    <img src="https://cdn.jsdelivr.net/gh/Cudytech-pr/User-Guide/docs/images/tutorial/sn.webp" width="300px" style="display: block; margin: 0 auto;border: 1px solid #eee;">    
   
9. After the switch is successfully added, you can start to manage the switch anytime and anywhere using the Cudy App.
